# kirby-plr-email-sequences

*This skill is part of the [Kirby Skills Collection](https://github.com/markkirby125/kirby-skills-collection).*

Transforms generic, informational PLR articles and reports into 10 distinct high-converting email autoresponder sequences calibrated for relationship building and direct response.

Copy and paste this directly to your AI (Cursor, Windsurf, Claude Code, Antigravity):

```markdown

1. Read the `SKILL.md` file from this repository: https://github.com/markkirby125/kirby-plr-email-sequences
2. Identify the correct rules system for our current environment (e.g., `.cursor/rules/` for Cursor, `.windsurfrules` for Windsurf, `.clinerules` for Cline, or `~/.agents/skills/` for Antigravity).
3. Save the contents appropriately.
4. Confirm when the installation is complete.
```

## Manual Installation

- **Cursor**: Save `SKILL.md` to `.cursor/rules/kirby-plr-email-sequences.mdc`
- **Windsurf**: Save `SKILL.md` to `.windsurfrules`
- **Antigravity / Agent CLIs**: Clone this repository into `~/.agents/skills/kirby-plr-email-sequences`
